# 愿景与范围

## 1. 愿景

建立一个**可长期维护、可开源、设计驱动**的个人网站：用一页讲清"我是谁"，用一套结构化案例讲清"我做过什么"，并让不同领域的项目在同一套信息架构下被公平、清晰地呈现。

网站不是简历的网页版，而是**作品与方法的展示面**：读者应能在 3 分钟内理解技术栈广度，在 10 分钟内通过任一案例理解问题、约束、方案与结果。

## 2. 目标用户

| 用户 | 场景 | 关心什么 |
|---|---|---|
| 招聘方 / HR | 快速筛选候选人 | 定位、技术广度、项目真实性、联系方式 |
| 技术面试官 | 深挖项目细节 | 架构决策、指标、取舍、可复现性 |
| 合作方 / 客户 | 评估能力匹配 | 领域经验、交付质量、沟通方式 |
| 学术同行 | 了解研究经历 | 科研项目、方法、产出 |
| 开发者 / 开源社区 | 复用或贡献 | 代码质量、文档、许可证 |

## 3. 价值主张

1. **广度可见**：7 个领域（大模型、计算机视觉、数据分析、嵌入式、基础设施、Web 工程、科研）在同一导航与筛选体系下呈现，避免"看起来只会一件事"。
2. **深度可信**：每个案例按"背景 → 约束 → 方案 → 决策 → 结果 → 反思"六段式写作，不堆砌技术名词。
3. **体验优先**：移动端优先的排版、深浅主题、可访问性 AA、亚秒级 LCP、无第三方跟踪。
4. **可持续**：内容与代码分离，新增项目只需加一个 MDX 文件；全流程 CI 门禁与文档同步。

## 4. 范围

### 4.1 纳入范围

| 模块 | 内容 |
|---|---|
| 首页 | 个人定位、精选项目、领域总览、能力矩阵、履历摘要、联系方式 |
| 项目库 | 领域筛选、标签筛选、排序、搜索、空态、URL 状态同步 |
| 项目详情 | 六段式案例、指标、图库、技术栈、外链、相关项目 |
| 关于 | 自述、技能、教育、经历、工具、联系方式 |
| 搜索 | Pagefind 静态全文搜索，快捷键唤起 |
| 元数据 | sitemap、RSS、robots、JSON-LD、OG 图、`projects.json` |
| 工程 | Git、CI、测试、性能预算、可访问性门禁、MIT 许可与社区文件 |

### 4.2 非目标（本期明确不做）

| 非目标 | 原因 |
|---|---|
| 运行时后端 / 数据库 | 个人站无此需求；静态部署零运维、零成本 |
| 账号体系与登录 | 无用户生成内容 |
| 评论系统 | 维护成本高、审核负担大；如需交流用邮件 |
| 默认接入 CMS | Git 工作流已足够；后续可选 Sveltia CMS |
| 英文正文 | MVP 聚焦中文；i18n 字典与路由预留 |
| 重型 WebGL / 3D | 收益低、性能与可维护性代价高 |
| 多作者协作 | 个人站，单维护者 |

### 4.3 边界与假设

- 单仓库、单站点、单部署目标（GitHub Pages 为主，Cloudflare Pages 为辅）。
- 内容以中文为主，项目 slug、代码标识符用英文。
- 个人信息发布前须脱敏（详见 `12-security-privacy-licensing.md`）。

## 5. 成功指标（KPI）

| 维度 | 指标 | 目标 | 测量方式 |
|---|---|---|---|
| 性能 | Lighthouse 移动端 Performance | ≥ 95 | LHCI |
| 性能 | LCP / CLS / TBT | ≤1.8s / ≤0.05 / ≤150ms | LHCI |
| 体积 | 首页 JS（gzip） | ≤ 25KB | `scripts/check-budget.mjs` |
| 可访问性 | axe serious + critical | 0 | Playwright + axe |
| SEO | 结构化数据校验 | 全部通过 | 集成测试 |
| 内容 | 上线项目数 | ≥ 12，覆盖 ≥ 5 个领域 | 内容清单 |
| 工程质量 | 单测覆盖率（`src/lib`） | ≥ 80% | Vitest coverage |
| 文档 | M0–M6 文档完成度 | 100% | `scripts/check-docs.mjs` |
| 维护性 | 新增一个项目耗时 | ≤ 10 分钟 | 自我计时记录 |
