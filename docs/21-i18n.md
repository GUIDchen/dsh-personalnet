# 中英文界面与路由

> 范围：界面文案、页面元数据与个人资料双语；项目/笔记正文暂保持中文。英文路由为显式 `/en/` 前缀，不启用运行时语言检测。

## 1. 语言模型

| 语言 | URL | `html lang` | 内容 |
|---|---|---|---|
| 中文（默认） | `/`、`/projects/` 等 | `zh-CN` | 全部页面与正文 |
| 英文 | `/en/`、`/en/projects/` 等 | `en` | 界面、元数据、个人资料为英文；项目/笔记正文为中文并标注 |

- 语言以 URL 为准，不使用 cookie/localStorage 自动跳转，避免 SEO 与分享链接歧义。
- 英文页面中引用中文内容的区域带 `lang="zh-CN"`（项目卡标题/摘要、笔记标题/摘要、CV 项目列表）。
- 项目与笔记详情页没有英文版本：英文列表中的卡片直接链接中文详情，并在页面标注 "Case studies are currently in Chinese."。
- 语言切换：`/en/` 加/去前缀；详情页切换到英文时回退到 `/en/projects/` 或 `/en/notes/`，避免 404。

## 2. 路由

| 中文 | 英文 |
|---|---|
| `/` | `/en/` |
| `/projects/` | `/en/projects/` |
| `/notes/` | `/en/notes/` |
| `/about/` | `/en/about/` |
| `/cv/` | `/en/cv/` |
| `/search/` | `/en/search/` |
| `/now/` | `/en/now/` |
| `/uses/` | `/en/uses/` |
| `/404.html` | `/en/404/` |
| `/projects/<slug>/` | 无（链接中文详情） |
| `/notes/<slug>/` | 无（链接中文详情） |

英文路由文件位于 `src/pages/en/`，每个文件只做一件事：导入对应的页面组件并传入 `lang="en"`。页面组件通过 `lang` 选择字典、个人资料与链接前缀，从而避免复制整页模板。

## 3. 代码结构

| 文件 | 职责 |
|---|---|
| `src/i18n/index.ts` | `Lang` 类型、`ui` 界面字典、`copy` 页面文案、`format()` 占位符替换 |
| `src/i18n/routing.ts` | `getLangFromUrl`、`localizePath`、`switchLanguagePath`、`getAlternates` |
| `src/data/profile.en.ts` | 英文个人资料（姓名、定位、bio、地点、可用状态） |
| `src/data/timeline.en.ts`、`skills.en.ts` | 英文经历与技能分组 |
| `src/data/now.en.ts`、`uses.en.ts` | 英文 Now / Uses 数据 |
| `src/data/domains.ts` | 领域英文标签与描述（`labelEn`/`descriptionEn`） |

规则：

1. 新增界面文案必须同时补 `zh` 与 `en`，缺失会导致类型错误。
2. 新增页面若需要英文版，页面组件接受 `lang?: Lang`，并新增 `src/pages/en/` 薄包装。
3. 正文内容（项目/笔记）不进入字典；英文页面通过 `lang` 标注中文区域。
4. 所有站内链接使用 `localizePath()`，不要在页面里手写 `/en/` 前缀。

## 4. SEO

- `BaseLayout` 输出 `<html lang>`、`og:locale`、`og:locale:alternate`。
- `Meta` 输出 canonical 与 hreflang：`zh-CN`、`en`、`x-default`（默认指向中文）。
- 只有存在对等页面的路由才输出 `en` alternate；项目/笔记详情只输出 `zh-CN` 与 `x-default`。
- `check-seo.mjs` 允许 `zh-CN`/`en`；title/description 唯一性按全站检查；英文 description 仍限制 20–160 字符。
- 英文搜索页与所有 404 保持 `noindex`；sitemap 排除 search 与 404（含英文）。

## 6. 已知边界

- 项目/笔记正文未翻译；英文页面只提供界面与元数据。
- 没有英文 RSS（RSS 仍以中文内容为主）。
- 根 404 由托管平台返回 `404.html`；`/en/404/` 仅用于语言切换与直接访问。
- 英文页面的 Pagefind 结果标题仍为中文原文，搜索本身跨语言。
- 字典是手写的，没有接入翻译平台；后续内容量增大时可迁移到 TMS。
