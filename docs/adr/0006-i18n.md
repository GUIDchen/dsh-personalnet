# ADR 0006：中文优先，i18n 预留

## 状态

Accepted（2026-10-23）

## 背景

站点主要面向中文读者；英文正文会显著增加内容维护成本。

## 决策驱动因素

- MVP 聚焦内容质量
- 未来可低成本扩展英文
- SEO 避免重复内容

## 考虑过的选项

- **中文单语 + 预留字典与路由**：成本最低，扩展清晰
- **中英双语从第一天开始**：覆盖更广，但内容工作量翻倍
- **纯英文**：不符合主要读者

## 决策

MVP 仅中文正文；UI 文案集中在 `src/lib/i18n/`，日期用 `Intl`；路由预留 `/[lang]/` 结构与 `hreflang` 生成逻辑，但本期不产出英文页面。

## 后果

### 正面

- 内容投入集中在质量
- 后续加英文不需要重构

### 负面

- 短期内国际读者只能读中文

### 后续行动

- M7 若启动英文，先翻译首页/关于/项目摘要，再逐步补案例正文。
