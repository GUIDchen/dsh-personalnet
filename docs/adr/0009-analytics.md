# ADR 0009：分析默认关闭，隐私优先

## 状态

Accepted（2026-10-23）

## 背景

作品集需要了解访问来源，但不应以隐私或性能为代价。

## 决策驱动因素

- 无 Cookie、无跨站跟踪
- 默认零第三方请求
- 可随时关闭

## 考虑过的选项

- **默认无分析**：最隐私，但无数据
- **Umami（自托管/云）**：开源、隐私友好、可关闭
- **Plausible**：优秀，但自托管需运维
- **Google Analytics**：数据丰富，但隐私与合规风险高

## 决策

默认不加载任何分析脚本；通过 `PUBLIC_ANALYTICS_ID` 与 CSP 白名单启用 Umami，文档说明数据范围。

## 后果

### 正面

- 默认零第三方请求，CSP 更严格
- 需要时一行环境变量开启

### 负面

- 默认没有访问数据

### 后续行动

- 若启用，同步更新隐私说明与 CSP；不接入任何广告或指纹脚本。
