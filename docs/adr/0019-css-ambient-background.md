# ADR 0019：全站环境背景采用纯 CSS 3D 网格

## 背景

背景需要更有氛围，但站点以内容阅读为主，必须避免图片 LCP、WebGL 包体和动画电量成本。

## 决策

使用纯 CSS 的极光渐变 + 透视网格作为全站背景：

- 固定在视口、负层级、不参与布局；
- 颜色跟随主题 token；
- 移动端简化；
- `prefers-reduced-motion` 停止动画；
- 后台 bare 页面不挂载。

不引入 Three.js/Spline/视频/摄影背景。

## 后果

### 正面

- 零 JS、零图片请求；
- 主题自适应、易降级；
- 视觉空间感明显但不过度。

### 负面

- 不是真 3D、不可交互；
- 动画在极低端设备仍需 reduced-motion 降级；
- 若未来要真 3D，需另建实验页与预算。
