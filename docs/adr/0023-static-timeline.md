# ADR 0023：时间线采用静态 HTML/CSS

## 背景

项目周期/领域分布/经历数据量小，图表库会增加 JS 与可访问性负担。

## 考虑过的选项

- **Chart.js/Recharts**：交互与图例成熟，但增加 JS、CSP 与可访问性负担。
- **构建期 SVG 图表**：可控，但需要额外布局/坐标计算与响应式处理。
- **CSS grid 条形 + 表格**：零图表库、天然可读/可打印，适合 12 条数据。
- **静态图片**：不可缩放、不可读屏，排除。

## 决策

- 以 CSS grid 条形 + 可访问表格渲染。
- 数据计算放在 src/lib/timeline.ts，可单测。
- 不引入 Chart.js/D3/Recharts。
- 移动端改纵向布局；颜色不是唯一信息载体。

## 后果

优点：零图表 JS、可读/可打印、易维护。
代价：复杂交互/缩放能力有限；若未来数据量大幅增长再评估。
