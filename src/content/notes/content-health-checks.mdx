## 问题

内容型站点最怕"看起来完成"：页面能打开，但案例没有截图、没有仓库、没有可验证指标。靠人工记忆很容易漏。

## 做法

为每个已发布项目计算五项：

1. GitHub 源码；
2. 封面；
3. 图库；
4. 指标；
5. Demo / 论文 / 文档。

仪表盘汇总完整度并列出缺失项，链接直接跳到对应 CMS 条目。缺失不是构建错误，而是内容待办；没有证据的项目不会伪造链接或截图。

## 为什么放在构建期

健康度是内容的函数，不需要数据库。Astro 在构建时读取 content collection，算出统计并静态输出；后台不需要额外 API，也不会把 token 放进浏览器。

## 边界

- 只能检查"有没有"，不能判断"好不好"。
- 指标与链接需要作者提供；脚本不推测。
- 旧内容补齐后，下一次构建自动更新。

## 实现索引

- `src/pages/admin/index.astro`：证据完整度与缺失清单。
- `scripts/content-audit.mjs`：命令行证据表。
- `scripts/health-report.mjs`：定时健康报告。
